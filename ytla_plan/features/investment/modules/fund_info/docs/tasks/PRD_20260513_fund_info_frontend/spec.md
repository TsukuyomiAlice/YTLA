# 基金信息模块 - 后端API开发

## 概述
- **摘要**: 为基金信息模块开发后端API，支持前端展示基金基本信息和历史净值数据
- **目的**: 提供RESTful API接口，支持前端页面获取基金数据，包括净值历史数据用于折线图展示
- **目标用户**: 前端开发人员

## 目标
- [G1] 提供获取基金基本信息的API（兼容旧API）
- [G2] 提供获取基金历史净值数据的API，支持折线图展示
- [G3] 提供获取最新基金净值的API
- [G4] 遵循现有项目架构规范

## 非目标
- 不修改现有DAO层代码
- 不修改数据库结构

## 背景与上下文
- 现有系统已有完善的DAO层和业务逻辑
- 前端需要API来获取数据展示
- 参考linguisticEnglish模块的架构
- 旧API在 `app_old.py` 中，需要兼容

## 功能需求
- **FR-1**: 获取基金基本信息API（兼容旧的 fundInfo 接口）
- **FR-2**: 获取基金历史净值API，返回完整的日期和净值数据用于折线图
- **FR-3**: 获取基金最新净值API

## 验收标准
### AC-1: 基金基本信息API
- **Given**: 请求获取基金信息
- **When**: 传入基金代码
- **Then**: 返回基金基本信息（代码、名称、类型、净值等）
- **Verification**: `programmatic`

### AC-2: 基金历史净值API
- **Given**: 请求获取基金历史净值
- **When**: 传入基金代码
- **Then**: 返回完整的历史净值数据列表，包含日期和净值，用于前端折线图展示
- **Verification**: `programmatic`
