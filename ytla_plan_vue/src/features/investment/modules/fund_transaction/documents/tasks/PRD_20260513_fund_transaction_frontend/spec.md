# 基金交易模块 - 前端页面开发

## 概述
- **摘要**: 为基金交易模块开发前端页面，展示交易记录和即时分组分析结果
- **目的**: 提供直观的交易管理和分析界面，展示分组统计策略，选择基金后即时分析
- **目标用户**: 基金投资者、交易分析员

## 目标
- [G1] 实现交易记录管理页面（兼容旧API）
- [G2] 实现即时分组交易分析展示，选择基金后即时计算
- [G3] 实现持仓统计展示
- [G4] 实现自动化任务触发
- [G5] 遵循项目Vue3架构规范
- [G6] 展示完整的分析结果，包括基金概况、分组明细、利润统计等

## 非目标
- 不重新设计分析算法（使用后端已有算法）
- 不实现用户管理功能
- 不生成文档文件（改为即时展示）

## 背景与上下文
- 后端会提供相应的API，支持即时分析
- 有实际分析结果文档作为参考
- 参考language模块的前端架构
- 使用Vue3 + TypeScript
- 需要与 fund_info 模块有导航切换
- 从"按钮生成文档"改为"选择基金即时分析"

## 功能需求
- **FR-1**: 交易记录列表和添加（兼容旧API）
- **FR-2**: 选择基金代码，即时获取分组交易分析结果
- **FR-3**: 展示完整分析结果：基金概况、连续涨跌统计、分组交易明细、利润统计等
- **FR-4**: 持仓统计信息展示
- **FR-5**: 自动化任务执行
- **FR-6**: 页面导航，可切换到基金信息模块

## 验收标准
### AC-1: 交易记录管理
- **Given**: 用户访问交易记录页面
- **When**: 查看或添加交易记录
- **Then**: 页面正常展示和操作
- **Verification**: `human-judgment`

### AC-2: 即时分组分析展示
- **Given**: 用户选择基金代码
- **When**: 点击分析按钮
- **Then**: 即时获取并清晰展示完整的分组交易分析结果
- **Verification**: `human-judgment`

### AC-3: 自动化任务
- **Given**: 用户点击执行任务
- **When**: 任务执行完成
- **Then**: 显示执行结果
- **Verification**: `human-judgment`

### AC-4: 页面导航
- **Given**: 用户在基金交易页面
- **When**: 点击导航按钮
- **Then**: 可以切换到基金信息页面
- **Verification**: `human-judgment`
